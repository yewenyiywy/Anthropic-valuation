## 2. 总估值模型（Overarching model）

主模型是开放式、带停留时间与财务隐状态的联合 Markov 收入递推，结合共同宏观周期、供应商选择、个人订阅需求以及有限期限 DCF。计算顺序：收入基准 → 需求上限及客户状态 → 存量转移与新增获客 → 收入 → 自由现金流 → 生命周期延续价值 → 股权价值。

每条路径的企业收入由试点、正式部署及企业席位三个不同账本构成。令状态张量 X 的维度为企业生命周期 i、停留时间 d、财务健康 h、供应商 v；共同周期 Z 独立作为条件过程。

```math
\widetilde X_t^{(b)}=\mathcal K_{Z_t}\big(\mathcal G_t^{(b)}(X_{t-1})M_{Z_t}\big)+A_t^{(b)}
```

```math
E_t=\sum_{b,i,d,h,v}\widetilde X_{idhv,t}^{(b)}r_v,\qquad R_t=\min(E_t,C_t)+B_t^{\mathrm{personal}}
```

```math
V^{(\ell)}_{\mathrm{equity}}=\sum_{t=1}^{10}\frac{FCF^{(\ell)}_t}{(1+W)^t}+\sum_{t=11}^{30}\frac{\mathbb E[FCF_t\mid R_{10}^{(\ell)}]}{(1+W)^t}+Cash-Debt
```

```math
\widehat V_{\mathrm{equity}}=\frac{1}{1024}\sum_{\ell=1}^{1024} V^{(\ell)}_{\mathrm{equity}}
```
其中 G 为试点转化、金额增长与支出的账本预处理（详见5.6），b 为账本，K 为包含财务、存活、晋级与支出变化的收入加权算子，M 为供应商条件转移矩阵，A 为新增账单，C 为行业上限。试点转正式部署及价格用量因子在下文展开。各条路径先计算现金流后求平均。

### 4.2 雇主覆盖与个人订阅替代

用量和订阅属于账单类别，而不是去重用户。将订阅拆为个人与企业账单（初始个人占比假设为50%）。A 表示个人付费，B 表示雇主提供 AI。

```math
\Pr(A\cup B)=\Pr(A)+\Pr(B)-\Pr(A\cap B)
```

```math
\Pr(A)=\Pr(A\mid B)\Pr(B)+\Pr(A\mid B^c)(1-\Pr(B))
```

```math
\kappa=1-\frac{\Pr(A\mid B)}{\Pr(A\mid B^c)},\qquad \Pr(A)=\Pr(A\mid B^c)(1-\kappa\Pr(B))
```

两笔真实独立账单均计入收入，仅调整条件需求。雇主覆盖率从 e0 插值至 e10。个人收入相对基准重叠程度调整；企业订阅递推见第5.6节。

```math
e_t=e_0+(e_{10}-e_0)\min(t/10,1)
```

```math
B^{raw}_t=B^{raw}_{t-1}(1+bd_t)
```

```math
B_t^{personal}=\min\left(B_t^{raw}\frac{1-\kappa e_t}{1-\kappa e_0},R_C+\max(0,B_0^{personal}-R_C)\max(0,1-t/5)\right)
```

每期将原始订阅累计值更新为受限个人收入除以重叠系数。

### 5.5 供应商竞争、Token 定价与商业化

供应商状态为仅Claude、含Claude的多模型、OpenAI、Google、自建、其他、不采购；收入回报权重(1,.60,0,0,0,0,0)。Ramp 2026年1月Claude客户79%也向OpenAI付费，以相同总预算假设初始化并归一化至Claude收入，不是支出占比；9月月度改变首要供应商占比8%，不是取消率。Menlo 2026估计API支出份额Claude55%、OpenAI31%、Google9%，不是转移概率。既有条件商业流失只计算一次，并分流到其他供应商或停购；分流比例.35/.25/.15/.10/.15。正常环境从竞争者回流6%，停购回流3.5%，单/多模型条件互切12%/4%，均是假设。竞争者状态为聚合代理；初始竞争者质量为0，新增销售与迁回并存，尚未独立估计有限市场池及潜在重叠。

基本恒等式：

```math
R_{\mathrm{token},t}=Q_t P_t M_t
```

$Q_t$ 为 Token 总用量，$P_t$ 为每 Token 实际美元价格，$M_t$ 为统一价格口径下的供应商用量份额。

份额不变时，抵消价格跌幅 $\delta$ 所需的用量增长为：

```math
g_Q=\frac{1}{1-\delta}-1
```

```math
\delta=50\%\quad\Longrightarrow\quad g_Q=100\%
```

预测中的年度乘数逐渐趋近于1：

```math
d_t=\max\left(0,1-\frac{t-1}{7}\right)
```

```math
G(L,p,m,r)=L\left[pm+(1-p)r\right]
```

| 符号 | 定义 |
|---|---|
| $L$ | 现有试验项目收入 |
| $p$ | 成功部署比例（假设按收入加权） |
| $m$ | 成功后支出扩张倍数 |
| $r$ | 失败项目剩余支出 |

当前预测设 $r=0$，将成功项目转入正式部署账本（不改变企业生命周期状态）：

```math
G_t=p\,m\,L_{t-1}
```

收入持平示例：

```math
G(100,0.25,4,0)=100
```

### 7.1 为什么替换 Gordon Growth Model？

Gordon 模型假设持续经营的企业，其标准化现金流按固定速率无限期增长：

```math
TV_T=\frac{FCF_T(1+g)}{W-g}
```

若现金流假设成立且折现率大于增长率，该公式数学上有效。但对于面对商品化、价格竞争和商业模式替代的年轻模型供应商，不宜默认使用。Gordon 也允许零或负增长；真正的问题是强制设定一种永久状态。

- [Chan, Karceski and Lakonishok (2003)](https://www.nber.org/papers/w8282) 发现企业长期盈利增长的持续性较弱，可预测性有限。
- [BLS 2013年群组](https://www.bls.gov/opub/ted/2024/34-7-percent-of-business-establishments-born-in-2013-were-still-operating-in-2023.htm): 34.7%的商业经营单位存活十年。
- [BLS 2000年群组](https://www.bls.gov/opub/ted/2026/outlast-state-establishment-survival-rates-from-2000-to-2026.htm): 15.7%存活26年。这些是经营单位，并非匹配的上市科技公司；两项数据均不能直接校准 Anthropic 的退出风险。

行业增长不保证单个企业现金流增长。产业收益可能被客户及竞争者获得。新模型允许衰退、转型和吸收性退出。使用30年有限期限，之后剩余价值为零，是保守截断假设，并非证明公司必然消失。

第10年初始状态为成熟经营。状态顺序：成熟、衰退、转型、退出。退出为吸收状态。年度退出概率 e、衰退概率 d、转型概率 u 均为假设，尚未拟合。

```math
P=\begin{pmatrix}1-e-d-u&d&u&e\\0.10&1-e-0.10-u&u&e\\0.40&d&1-e-0.40-d&e\\0&0&0&1\end{pmatrix}
```

```math
\pi_{10}=(1,0,0,0),\qquad \pi_t=\pi_{t-1}P
```

按状态跟踪概率加权收入，而非仅用概率乘固定收入，从而保留路径依赖增长。

```math
a_{10}=(R_{10},0,0,0),\qquad a_t=a_{t-1}P\,\mathrm{diag}(1,0.85,1.08,0)
```

```math
E[R_t]=\sum_j a_{t,j}
```

各状态假定的标准化税后现金流利润率分别为15%、3%、20%、0%，已经包含普通可变算力、其他费用和资本开支。远期阶段没有新增收入上限。无合同解除的压力测试即使退出仍承担剩余承诺；实际清偿或回收尚未建模。

```math
E[FCF_t]\approx \sum_j a_{t,j}\mu_j-\max(0,K^{floor}_t-cE[R_t])
```

由于凸性，总量承诺缺口是下界，并非精确的期望缺口。

```math
EV_0=\sum_{t=1}^{10}\frac{FCF_t}{(1+W)^t}+\sum_{t=11}^{30}\frac{E[FCF_t]}{(1+W)^t}
```

```math
V_{\mathrm{equity}}=EV_0+212.684-110.873
```

备考现金和可转债账面价值仅为示例；最终资本结构、偿还条款和稀释仍待核对。不假设期末出售价值或第30年后的现金流。退出概率不应与 WACC 中信用风险重复计算。

### 8.2 历史公司特定验证

样本锁定为[1999 年 9 月 8 日互联网公司市值前十](https://www.internetnews.com/it-management/new-internet-giants-roam-the-street/)，保留后来破产与并购的企业。[历史数据表](data/dotcom_vintage.csv)记录[1999 年 9 月 Bear Stearns 研究报告 Exhibit 2](https://people.duke.edu/~charvey/Teaching/BA491_2000/Cc/Cc_BS.pdf)的同期预估和独立 SEC 验证数据。空值表示缺失，不能当成零。已取得的五家公司 CY2000 分析师预测 MAPE 为 24.87%，仅作为**外部基准**，不是本联合状态模型的准确率；其余五家缺少可比外部预测。长期回测还须处理并购和财年差异。

```math
\operatorname{MAPE}=\frac1n\sum_i\left|\frac{\widehat R_i-R_i}{R_i}\right|
```

联合状态引擎已支持显式公司参数：初始收入账本、客户权重和留存、生命周期与供应商转移、收入奖励、新客户、市场上限、成本和有限远期价值。缺少完整公司参数时拒绝运行，而非借用 Claude 参数。此前统一收入曲线的缩放实验不是有效公司特定回测。公司自身破产及并购与客户退出是不同事件，需要独立估计。

新增[十家公司财年收入面板](data/dotcom_fy_panel.csv)和[可运行回测代码](evaluation/company_oos.py)，实际调用联合状态转移算子进行聚合降维实验。各家公司采用自身 FY1998–99 收入，共用50%对数增长收缩和七年线性衰减：

```math
\widehat R_{i,t}=\widehat R_{i,t-1}\exp\left[0.5\log(R_{i,1999}/R_{i,1998})\max(0,1-(t-1)/7)\right]
```

| 测试 | 样本数量 | MAPE | WAPE | 误差20%以内 |
|---|---:|---:|---:|---:|
| FY2000同期预测 | 10 | 21.54% | 19.41% | 50% |
| FY2001–04未来验证 | 23 | 304.61% | 64.35% | 13.04% |
| 一年半衰期压力测试，FY2001–04 | 23 | 87.72% | 33.48% | 26.09% |

FY2000收入不变基准与原增长率直接外推基准MAPE分别为50.23%和129.32%。七家原始或已核对披露的输入子样本MAPE为21.35%，三家为事后重构。FY2000财年与输入披露时间重叠，因此不是严格全期样本外；破产或合并后的缺失值不等于零。一年半衰期是事后压力测试，不是独立验证的参数。仅使用FY1997–99数据留一公司拟合增长持续性，FY2000 MAPE为121.83%，FY2001–04为88,714.78%，说明繁荣期增长持续性不可直接移植。

这**不是**完整客户状态或股权估值回测：仅凭总收入无法识别获客、流失、定价、成本和公司破产。没有定义并预测破产标签，不能计算召回率。长期验证拒绝了该聚合增长外推。

#### 五年终点验证（FY1999至FY2004）

[补充的SEC财报数据](data/dotcom_five_year.csv)提供八家公司可评分的2004年收入；AOL并购与Excite破产不纳入收入百分比误差，不等于预测成功。原模型五年MAPE/WAPE为1,106.82%/230.14%；一年半衰期120.15%/49.06%；收入不变73.03%/61.19%。

聚合校准模型先限制初始对数增长，再指数衰减：

```math
g_{i,0}=\operatorname{clip}(\alpha\ln(R_{i,1999}/R_{i,1998}),-c,c),\quad g_{i,t}=g_{i,0}2^{-(t-1)/h}
```
```math
\widehat R_{i,t}=\widehat R_{i,t-1}\exp(g_{i,t})
```

完全留出目标公司，使用其他公司FY2000–03收入的平均绝对对数误差拟合参数，所有FY2004结果均不参与拟合。五年MAPE/WAPE为76.48%/41.08%。这是事后跨公司迁移及终点留出，而不是1999年信息集实时校准。加入成熟增长率的扩展MAPE反而升至94.52%；收入不变基准在MAPE仍占优。[可执行代码](evaluation/five_year.py)。
