# Source register
observations.csv is a manually transcribed, point-in-time snapshot as of 2026-11-19; source URLs, period, units, scope and evidence kind accompany every value. Filing = issuer disclosure, sample = observed sample, survey = respondent/project survey, proxy = indirect evidence. Do not infer global paid share from US usage, multiply VC company-count share by spend concentration, or equate venture deal participation with direct funding share. SEC November 17 S-1/A pro forma cash is illustrative, not final IPO cash. The 81B run rate is not full-year revenue. All cash figures are USD billions. Source revisions can occur. Country income classification: https://databank.worldbank.org/metadataglossary/world-development-indicators/country/HIC (FY27 thresholds 1175 / 4635 / 14375 USD GNI per capita). No verified global paid rate or country-level Claude spend is available in this snapshot; leave missing fields unspecified.

- `stage4_origin_inputs.csv`: stage-4 roster origin inputs (USD B). Original-vintage SEC XBRL facts from the latest annual filing filed on or before the origin (`filed`, `accn`). No post-origin values. Single-source; second reconciliation against filing HTML pending. Capex = PP&E purchases (`PaymentsToAcquirePropertyPlantAndEquipment`, `PaymentsToAcquireProductiveAssets` or `PropertyPlantAndEquipmentAdditions`) plus capitalized software where tagged.
- `margin_dev_panel.csv`: development-only margin panel (exposed families). Same input rule; `target_*` columns are from the first annual filing reporting the fiscal year that ends in the target calendar year.
- `stage4_margin_labels.csv`: target-fiscal-year cash-flow labels for the stage-4 roster, from the first annual filing reporting that year (`accn`, `filed`). Acquired issuers have no label (blank), never zero. Opened once on 2026-11-19 after predictions were frozen.
- `stage4_exit_events.csv`: acquisitions closing within the five-year window, with close date, per-share consideration and headline value. `value_basis` flags equity vs enterprise headlines; replace with per-share × diluted shares before any release scoring.
- `sec_reconciliation.csv`: second-source check for every SEC value used by the margin, growth and exit components (205 values, 41 filings). Each XBRL value was located in the filed primary document (or financial-statement exhibit) at the stated line item. All 205 match exactly in the reported unit; 34 are reported in USD millions, so they reconcile only to that rounding. Checked 2026-11-19.
- `legacy_reconciliation.csv`: item-by-item check of the pre-existing data. All 295 SEC-sourced values were located in the cited filing (or, where the link was dead or a scanned PDF, the same filing's full text submission or the next 10-K). Fixes: PayPal `cash20` 13.002→13.083 (cash + short-term investments; old value not reproducible), ServiceNow `cash20` 4.560042→3.092036 (dropped long-term investments so all issuers share one definition), Shopify `cash20` and Salesforce `da20` restored to full precision, eight dead or PDF links replaced. Non-SEC sources: 21 rows matched, Ramp token-share snapshot not reproducible (unused), 7 groups pending (IDC, market-cap sites, Menlo, Census, Gartner, McKinsey, JPM, ITU, 1990s non-SEC reports).
- `stage4_exit_events.csv` now carries a `second_source` per deal. NetSuite's 8.6 equity value rests on one source (the second gives the $9.3B EV headline only).
