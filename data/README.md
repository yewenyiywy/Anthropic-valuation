# Source register
observations.csv is a manually transcribed, point-in-time snapshot as of 2026-11-19; source URLs, period, units, scope and evidence kind accompany every value. Filing = issuer disclosure, sample = observed sample, survey = respondent/project survey, proxy = indirect evidence. Do not infer global paid share from US usage, multiply VC company-count share by spend concentration, or equate venture deal participation with direct funding share. SEC November 17 S-1/A pro forma cash is illustrative, not final IPO cash. The 81B run rate is not full-year revenue. All cash figures are USD billions. Source revisions can occur. Country income classification: https://databank.worldbank.org/metadataglossary/world-development-indicators/country/HIC (FY27 thresholds 1175 / 4635 / 14375 USD GNI per capita). No verified global paid rate or country-level Claude spend is available in this snapshot; leave missing fields unspecified.

- `stage4_origin_inputs.csv`: stage-4 roster origin inputs (USD B). Original-vintage SEC XBRL facts from the latest annual filing filed on or before the origin (`filed`, `accn`). No post-origin values. Single-source; second reconciliation against filing HTML pending. Capex = PP&E purchases (`PaymentsToAcquirePropertyPlantAndEquipment`, `PaymentsToAcquireProductiveAssets` or `PropertyPlantAndEquipmentAdditions`) plus capitalized software where tagged.
- `margin_dev_panel.csv`: development-only margin panel (exposed families). Same input rule; `target_*` columns are from the first annual filing reporting the fiscal year that ends in the target calendar year.
